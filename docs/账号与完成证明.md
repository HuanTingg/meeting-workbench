## 给成员分配账号

负责人登录 → 成员管理 → 分配账号/管理账号。填写账号、角色和初始密码，可以重置密码或停用账号。账号为3–40位字母、数字、点、下划线或连字符，不区分大小写；密码8–128字符。

普通成员只能访问自己的待办，可查看所有已发布会议及其录音，并上传、修改、解析、删除和发布自己上传的会议；他人的会议只读，未发布草稿不可见。已发布会议保持不可修改、删除。成员可给自己新增待办，不能替其他成员手动创建待办，也不能访问配置、通知记录或账号管理接口。负责人可以管理会议、任务、配置及所有账号。负责人不能停用或降级自己的账号，必须保留至少一个启用的负责人。

新建、重置密码后，下次登录要求修改密码。修改账号、停用或修改密码会使旧会话失效。会话最长8小时，退出登录或重启服务后需要重新登录。账号密码使用随机盐和 scrypt 哈希保存，接口不返回密码哈希。

## 成员完成任务

在“我的待办”点击完成复选框，弹窗中可填写完成说明并选一个附件，也可不填写说明、不上传附件直接确认完成。附件单个不超过10MB，支持 PDF、PNG/JPG/WEBP、TXT、Office文档、ZIP。

负责人在任务总览切换“已完成”或“全部”，按成员筛选，点击任务标题查看完成时间、提交人、说明及附件。附件以下载方式提供，仅限任务本人和负责人读取。重新打开任务会保留以往完成记录和附件。

## 数据位置与验证

账号保存到 MySQL“成员账号”中文表；完成历史保存在“待办事项”的“数据”字段；附件文件保存在 `data/completion-files`，文件名由服务端生成，不以用户上传名构造路径。备份时应同时备份数据库和 data 下的录音、完成证明文件。

自动测试覆盖未登录访问、跨成员读写拦截、账号角色、重置密码失效、首次改密、无附件完成、有附件完成、附件下载权限及 MySQL 持久化。暂未加入在线预览、多附件、完成情况审核流或自动反馈通知。

负责人手动新增待办后，按已启用的钉钉/飞书群通知和个人通知配置自动创建发送记录。通知失败不回滚已创建待办，可在相应配置页重试。
